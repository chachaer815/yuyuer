👤 管理员

📋 录新单

  1. 点击「订单新增」标签
  2. 填写到款单号 → 搜索选择业务员（支持关键词模糊搜索）
  3. 添加产品明细：型号 / 数量 / 货期
  4. 支持从 Excel 直接粘贴多行产品数据
  5. 点击「添加订单」提交，自动流转至仓库面板

👥 业务员管理

  1. 点击「业务员管理」标签
  2. 添加业务员（姓名 + 识别码）或停用已有业务员
  3. 设置「归属主管」，被设为下属的业务员订单会出现在主管的团队面板中

🏭 操作员

🔍 智能筛选栏

筛选触发条件使用场景
📅 待送货 业务员选了送货/验货时间，尚未送出 每天一筛，知道今天要送哪些
📅 待收回 业务员选了收回时间，尚未收回 验货/发货后筛出要拿回来的
📸 需拍照 业务员点了拍照请求 到货后拍照上传
📸 待拍照 有请求但未上传 优先处理
📷 已拍照 已上传图片 检查是否完善
✅ 需带来 业务员选了「是」 确认哪些单要拿过去

📦 完整操作流程

新单（待处理）→ 调货中 → 路途中 → 已到货 ↓ 筛「待送货」→ 日期橙色高亮 点【送货】→ ✓ 已送 ↓ 筛「待收回」→ 点【收回】 （日期、是否带来自动重置） ↓ 可多次循环送/收 结束：手动改「已完结」

💡 快捷操作

  1. 状态下拉、预计发货时间、进度回复：直接编辑，自动保存
  2. 单据日期 / 送货时间表头可点击排序
  3. 已送出的订单，点 ↩️ 可撤销
  4. 已收回的订单，可重新送货（支持多次循环）

💼 业务员

🔐 身份确认

登录后输入你的识别码，系统自动识别身份。主管会额外显示「我的订单 | 👑 团队订单」切换栏。

🔍 查订单

点击「搜索」查看自己全部订单，也可按到款单号或状态精确筛选。

📝 订单操作面板

字段说明
📸 拍照请求需要仓库拍照 → 选「是」并填写拍照要求（如"拍外箱+内件"）
✅ 是否带来需要仓库拿货过来 → 选「是」
📅 送货时间预计哪天送货（到货后才能选，选后橙色高亮）
🔍 验货时间需要验货的，选验货日期
📥 收回时间预计哪天仓库来收回
需要拿货 → 选「是否带来：是」→ 填对应时间 · 送货 → 填「送货时间」（到货后才可选） · 验货 → 填「验货时间」 · 收回 → 填「收回时间」 仓库筛「待送货/待收回」看到 → 执行送/收

👑 主管

  1. 登录后输入识别码，自动出现「我的订单 | 👑 团队订单」切换栏
  2. 团队订单显示每个业务员名字及订单状态
  3. 可点击「⚠️ 逾期未收回」筛选超期订单
  4. 主管只读查看，不修改下属订单
