👤 管理员

📋 录新单

  1. 点击「订单新增」标签
  2. 填写到款单号 → 搜索选择业务员（支持关键词模糊搜索）
  3. 添加产品明细：型号 / 数量 / 货期
  4. 支持从 Excel 直接粘贴多行产品数据
  5. 点击「提交订单」，自动流转至操作员面板

👥 业务员管理

  1. 点击「业务员管理」标签
  2. 添加业务员（姓名 + 识别码）或停用已有业务员
  3. 设置「归属主管」，被设为下属的业务员订单会出现在主管的团队面板中

🏭 操作员

🔍 智能筛选栏

筛选触发条件使用场景
📅 待发货 已到货 + 有验货/发货时间，尚未送货 每天一筛，知道今天要送哪些
📅 待收回 已到货 + 有收回时间，尚未收回 验货/发货后筛出要拿回来的
📋 待完结 有业务发货时间 + 未完结 业务员填了发货时间，点击直接改完结
📸 待拍照 有拍照请求但未上传 优先处理
📷 已拍照 已上传照片 检查是否完善
✅ 需带来 业务员选了「是」 确认哪些单要拿过去

💡 状态下拉 + 到款单号搜索 + 以上 checkbox 可任意组合使用

📦 完整操作流程

新单（待处理）→ 调货中 → 路途中 → 已到货 ↓ 筛「待发货」→ 点【送货】→ ✓ 已送 ↓ 业务员填「业务发货时间」 筛「待完结」→ 改「已完结」 ↓ （如需收回）业务员填「收回时间」 筛「待收回」→ 点【收回】 （验货日期、是否带来自动清空） ↓ 可多次循环（验货→送货→完结→收回→再验货）

💡 快捷操作

  1. 状态下拉、预计发货时间、进度回复：直接编辑，自动保存
  2. 单据日期 / 业务发货时间表头可点击排序
  3. 已送出的订单，点 ↩️ 可撤销
  4. 已收回的订单，清空验货/带来后可重新送货（支持多次循环）

💼 业务员

🔐 身份确认

登录后输入你的识别码，系统自动识别身份。主管会额外显示「我的订单 | 👑 团队订单」切换栏。

🔍 查订单

点击「搜索」查看自己全部订单，也可按到款单号或状态下拉精确筛选（选完自动出结果，无需点搜索）。「重置」可清空搜索返回首页。

📝 订单操作面板

字段说明
📸 拍照请求需要操作员拍照 → 勾选并填写拍照要求（如"拍外箱+内件"）
✅ 是否带来需要操作员拿货过来 → 选「是」
📅 业务发货时间操作员送货后，填这个日期通知操作员改已完结（到货后才能选）
🔍 验货时间需要验货的，选验货日期
📥 收回时间预计哪天操作员来收回（完结后才能选）

📌 时间填写规则

需要拿货 → 选「是否带来：是」→ 填对应时间 · 验货 → 填「验货时间」 · 送货后 → 填「业务发货时间」→ 操作员筛「待完结」改已完结 · 收回 → 填「收回时间」 操作员筛「待发货/待收回/待完结」看到 → 执行送/收/完结

📝 进度回复

操作员填写的进度回复显示在订单卡片上，超 20 字自动截断。鼠标悬停可查看完整内容。

🔔 通知中心

右上角铃铛显示未读通知数。操作员改状态 / 添加进度回复 / 上传照片后自动推送。点通知直接定位到对应订单，支持「全部已读」和「清空」。

👑 主管

  1. 登录后输入识别码，自动出现「我的订单 | 👑 团队订单」切换栏
  2. 团队订单显示每个业务员名字及订单状态
  3. 可点击「⚠️ 逾期未收回」筛选超期订单
  4. 主管只读查看，不修改下属订单

📊 角色与流程总览

角色核心功能权限
管理员 录新单 · 业务员管理 · 设置归属主管 全部管理权限
操作员 智能筛选 · 送货/收回循环 · 拍照上传 · 编辑状态 订单执行操作
业务员 查订单 · 拍照请求 · 验货/发货/收回时间 · 通知 自有订单操作
主管 团队订单查看 · 逾期筛选 只读查看下属
管理员录单 → 操作员处理（新单→调货→路途→到货） ↓ 业务员填写验货/发货/收回时间 + 拍照请求 ↓ 操作员执行送/收循环（可多次） ↓ 手动改「已完结」结束 · 支持尾款后循环
